## API Containers

### Required Env variables
- `BENTOML_DEFAULT_URL` - URL for the default bentoml service
- `BENTOML_HUBBLE_URL` - URL for the hubble bentom
- `BENTOML_DIRICHLET_URL` - URL for the dirichlet bentoml service
- `DATABASE_URL` - URL for the database connection
- `AZURE_STORAGE_CONNECTION_STRING` - Connection string for Azure Blob Storage
